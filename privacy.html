Privacy Policy – Kaam Khatam Pipeline

Last updated: 26 October 2026

What this app is

Kaam Khatam Pipeline is a private tool used only by the owner of the Kaam Khatam YouTube channel. It is not offered to the public.

What data it accesses

  • YouTube: uploads videos as private, updates their titles, descriptions, thumbnails and visibility, and reads basic video status — only on the owner's own channel.
  • Google Sheets: reads and writes the owner's own review sheet used to approve videos before publishing.

How data is stored

Sign-in tokens are stored only on the owner's own computer. The app does not collect, sell or share any personal data, and does not access any other user's account.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time from Google Account → Security → Third-party access.
